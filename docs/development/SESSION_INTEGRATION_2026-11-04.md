## 검사 도구 상태와 정리

중간 `ef34874a1cd345f5916634f636f71998`는 재컴파일 중 TestRunner 오류, `8d379f4487cf418c99c0482f0a98feec`는 테스트용 백그라운드 설정 저장 때문에 SourceChanged였다. 두 실행은 통과 증거로 사용하지 않았다. 컴파일 완료를 확인하고 백그라운드 설정을 임시 고정한 후 재실행했다.

끝에는 MainMenu·재생 중지·컴파일 중 아님·씬 미저장 변경 없음, `runInBackground=false`로 복원하고 자동 틱을 껐다. `pre-cleanup-source-files.json`과 `cleanup-source-diff.json`을 대조해 마지막 PlayMode 후 변경은 **ProjectSettings/ProjectSettings.asset의 백그라운드 설정 복원 하나뿐**임을 확인했다.

복원 후 최종 소스 해시는 `20f5d2ddd96a929910a931ceeb28b7f0df99e98e01c8295fe59b3f5bd459bff5`. Static `e036d4fc0d8148a6bb95406d9f49f8c5`가 이 해시에서 통과했다. Static의 testCount0은 Unity 게임 테스트가 추가로 통과했다는 뜻이 아니다. 복구 씬3쌍과 ProfilerCaptures는 보존했다.
