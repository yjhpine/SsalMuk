4. 사용자가 재요청하지 않으면 장시간 부하 검사나 전체 재검사를 시작하지 않는다. 향후 빌드 검증을 요청받으면 BuildValidator의 설정 메모리 캐시 복원 문제와 미검증 실행 도구 범위를 먼저 확인한다.
