# 실제 플레이·밸런스 조정

2026-09-17 시작. 기본 기능 구현 후 사용자가 추가 검사를 종료하고 다음 단계로 진행하도록 지시했다. 새 장시간 자동 검사나 전체 재검사를 시작하지 않는다. 현재 수치는 임시 출발값이며 실제 플레이의 체감에 따라 조정한다.

## 플레이 시작

Unity의 `Assets/_SsalMuk/Scenes/MainMenu.unity`에서 Play → `GameStart`로 시작한다. 이동·공격·경험치 수집은 AI가 담당하고 사람은 레벨업 선택지만 누른다. 선택 중에도 전투는 계속된다. 별도 실행 파일은 `Builds/SsalMuk/SsalMuk.exe`다. 자동 검사 인수를 전달하지 않고 일반 게임으로 실행한다.

## 조정 순서

1. AI 운영: 경험치를 적극적으로 수집하는지, 접촉 위험을 피하는지, 포위에서 한쪽으로 돌파하는지를 실제 플레이에서 판단한다. 막히는 행동을 체력 증가로 덮지 않는다.
2. 초반 난이도·성장: 첫 선택이 늦거나 연속으로 너무 많이 뜨는지, 검만 가진 초반이 지나치게 답답한지 확인하고 해당 수치 묶음만 바꾼다.
3. 무기 체감: 검·창·도끼·파이어볼의 거리와 주기, 추가 무기와 연속 공격의 느낌을 비교해 조정한다.
4. 시인성: 몬스터 군집, 반투명 범위, 피격, 발광 구슬이 서로 가리지 않게 표시 크기·강도를 조정한다.

## 현재 기준값

수치 에셋은 `Assets/_SsalMuk/Content/Definitions/DevelopmentDefaults.asset`이다. Unity에서 Play를 종료한 뒤 변경하고 새 판에서 적용한다. 아래는 현재 에셋 값이며 아직 밸런스 조정 결과가 아니다.

| 항목 | 현재 값 |
| --- | --- |
| 플레이어 체력 / 속도 | 100 / 3 |
| 일반 몬스터 체력 / 속도 / 접촉 피해 | 10 / 1.5 / 5 |
| 공중 몬스터 체력 / 속도 / 접촉 피해 | 6 / 6 / 5 |

AI 세부 판단값은 현재 `Assets/_SsalMuk/Core/AI/AiSettings.cs`와 각 상태에 있다. 에셋에서 바로 바꿀 수 있는 값으로 오인하지 않는다. 기본 운영 규칙과 5분 보스, 무기 4종·강화 5종, 무한 성장, 모든 몬스터·경험치 보존은 유지한다.

## 남겨 둔 검증 범위

10분 누적과 실제 Windows 게임 흐름까지 기존 성공 증거가 있다. 30분 누적 검사는 기한 초과로 미완료이며 후반 누적 부하를 해결했다고 보고하지 않는다. 추가 검증 도구의 미확인 범위도 [D3 결과](D3_VALIDATION.md)에 남긴다. 현재 단계에서 이 검사를 자동 재개하지 않는다.
