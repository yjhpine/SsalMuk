# 아이템과 전투 조정 구현 계획

**Goal:** 저장된 보스 반복·AI 조정을 마치고 네 아이템, 무기 개수 제한·각도, 끝부분에 붙는 공격 효과를 실제 플레이에 연결한다.

**Architecture:** 기존 C# 판 모델과 Unity 표현부를 유지한다. 아이템은 판에 속한 드롭과 시간제 효과로 처리하며 GameStart 이후 생성하고 사망·재시작 때 정리한다. 자석은 맵 전체의 기존 경험치에 흡수 상태를 부여하고 접촉 시 경험치를 지급한다.

**Tech Stack:** Unity 6000.4.6f1, C#, 기존 Unity CLI·검증 하네스.

**Spec:** 사용자 2026-09-22/24 지시, GAME_DESIGN.md, HANDOFF.md의 미완료 항목.

## 공통 제약

- 현재 프로젝트·브랜치에서 작업하고 기존 사용자 변경을 보존한다. 자동 전체/장시간 검사·Windows 재빌드는 하지 않는다.
- 근접 무기는 기본 포함 최대 8개, 좌우 교대 40도 간격. 파이어볼은 기본 포함 최대 6개, 좌우 교대 30도 간격. 연속 공격 강화 최대 2레벨 유지.
- 최소 보스 돌진거리는 추가하지 않는다. 예고 시 거리의 2배, 0.5초 예고, 30% 추가 1회, 묶음 뒤 5초를 유지한다. 후속 답변에 따라 돌진 속도는 예고 당시 강화·아이템을 포함한 플레이어 속도의 2배다.
- 자석은 모든 맵의 현재 경험치를 흡수한다. 무적 10초, 이동속도 1.5배 10초, 범위 10배 10초이며 재획득은 시간 갱신이다. 몬스터 처치 시 낮은 확률(임시 2%)로 4종 중 하나를 드롭한다.
- 후속 공용 강화: 단계마다 이동속도 +10%, 초당 회복 +0.1, 흡수 반경 +20%, 경험치 획득량 +25%. 증가율은 기본값에 선형 누적하고 경험치는 구슬 획득 시 0.5 이상 반올림한다. 무기별 강화와 함께 레벨업 선택지에 표시한다.

## 작업

- [x] 보스 반복 피격 재현과 일반 속도 0.95배, 보스 공격·풍부한 경험치 가중치 수정. 대상: Core/AI, DevelopmentDefaults, 관련 EditMode 테스트. 피격 대기 무한 초기화, 목표 변경, 접근 불가 경험치와 긴급 회피를 검증한다.
- [x] 무기별 각도·총수 상한을 성장 계산·선택지·실제 발사에 연결한다. 대상: 성장·스케줄러·공격 표시와 관련 테스트. 상한 이후 후보 제외와 초과 강화 거부, 좌우 교대 방향을 검증한다.
- [x] 무기 손잡이에서 끝부분까지의 길이와 공격 효과 위치를 같은 사거리 기준으로 맞춘다. 기본·강화·10배 범위의 실제 Unity 화면 및 도형을 확인한다.
- [x] 아이템 모델·획득·드롭·시간제 효과와 Unity 아이콘·남은 시간 표시를 추가한다. 자석 원거리 흡수·접촉 지급, 무적 10초 경계, 속도/범위 적용·종료·재시작, 실제 GameStart 드롭 연결을 검증한다.
- [x] 공용 강화 4종을 선택지·중복 선택 방지·실제 이동/회복/흡수/경험치 계산·사망 초기화에 연결한다. 큰 경험치 정수의 정확한 반올림과 체력 상한, 아이템 배율과의 결합을 검증한다.
- [x] 관련 검사 결과를 최종 소스와 대조하고 문서·인계 지점을 갱신한 뒤 로컬 커밋한다.

검증: 최종 소스의 관련 EditMode 154개·PlayMode 9개와 HighGrowth 750주기 통과. 실제 아이템/공용 선택 화면과 근접 기본/강화/10배 렌더 확인. 실행별 증거와 소스 해시는 [인계 문서](../../development/HANDOFF.md)의 2026-09-24 절에 기록한다.

## 검토 항목

- 반복 넉백 때문에 보스 대기가 영구 연장되지 않는가.
- 풍부하지만 접근 불가능한 경험치 때문에 플레이어가 멈추지 않는가.
- 자석이 먼 청크의 경험치를 삭제하거나 접촉 전에 지급하지 않는가.
- 재획득·사망·재시작 때 효과가 중복 곱해지거나 남지 않는가.
- 10배 사거리에서도 표시와 실제 판정이 일치하고 무기 상한이 선택지·실행 모두에 적용되는가.
