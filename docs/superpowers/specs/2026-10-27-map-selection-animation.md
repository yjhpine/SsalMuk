# 숲·도서관 선택과 플레이어 보행

2026-10-27 사용자 승인. 기존 단일 스프라이트 보행 스타일을 유지한다.

- 메인 메뉴에서 숲/도서관과 시작 무기를 선택한다. 기본 맵은 숲이며 재시작은 직전 선택을 유지한다.
- 숲은 청크마다 무작위 빈터를 배치하고 이동 공간을 연결한다. 나무·바위는 파괴 불가능한 지상 장애물이며 풀은 통과 가능한 정적 장식이다. 시작 공간과 보스가 지나는 여백을 보장한다.
- 도서관은 위아래가 막힌 가로형 무한 맵이다. 벽 내부에서는 상하좌우 이동한다. 지상 적은 벽 안의 화면 밖 공간에서 생성하고 공중의 기존 지형 통과는 유지한다.
- 기존 결정적 청크 생성·재방문 재현·화면 밖 몬스터/경험치 보존을 유지한다. 상자/아이템 합성은 이번 범위가 아니다.
- 플레이어만 Idle/Walk 클립과 Animator를 사용한다. Walk는 좌우 기울임과 작은 상승/착지를 반복하며 이동 입력이 없으면 정자세로 돌아간다. 추가 그림·본체 공격 동작·몬스터 보행·숨쉬기는 추가하지 않는다.
- 이동/공격/충돌은 기존 모델이 결정한다. 애니메이션은 시각적 자세만 바꾸고 피격 색·팽창은 별도로 적용한다. ESC 정지, 풀 반환/재사용 때 잔여 자세가 남지 않는다.
- 학습자료는 FSM/BT 연동과 Animation/Animator 선택을 안내한다. Animator 사용과 직접 클립 제작은 이 프로젝트의 선택이다.

임시 구현 수치: 도서관 내부는 세계 Y=3~29(높이 26), 숲 청크는 32×32, 중심/경계 연결 여백과 빈터를 확보한다. 세부 배치 밀도는 이후 조정 가능하다.
