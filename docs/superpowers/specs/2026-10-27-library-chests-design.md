# 도서관 경계·책장과 상자 탐험

사용자 요청: 불필요한 위아래 청크 제거, 벽 밀착 이동 완화, 책이 꽂힌 연속 책장 벽, 더 많은 가구, 랜덤 상자와 방향 화살표, 상자 우선 AI.

## 확정된 범위와 방식
- 도서관은 Y=0 청크만 생성/보관/표시한다. Y≠0은 청크를 만들지 않고 지형 질의에서 막힌 경계로 판정한다. 내부 Y=[3,29), 좌우 확장과 내부 상하좌우 이동은 유지한다.
- 단순히 외부 청크를 숨기는 방식은 충돌/탐색의 불필요한 생성이 남는다. 유한 높이를 지형 질의에도 반영하는 방식을 선택한다. 다른 맵의 청크 규칙은 유지한다.
- 벽은 청크당 한 정적 메시 안에 나무 프레임·선반·다색 책등을 반복 배치한다. 책마다 GameObject/Collider를 만들지 않는다. 내부 가구는 격자 슬롯의 확률 배치로 늘리고 중앙/가장자리 통로와 보스 통과 폭을 확보한다.
- AI는 도서관 벽에서 평상시 약 2단위의 몸통 여유를 선호한다. 경험치·버프 수집 중에는 픽업 반경을 기준으로 완화한다. 긴급 회피/돌파는 기존 안전도를 먼저 비교하고 동률일 때만 벽 여유를 고려한다. 벽 선호를 위험 비용에 더해 안전한 탈출 방향을 뒤집지 않는다.
- 상자는 두 맵의 접근 가능한 위치에 결정적으로 랜덤 배치하고 열린 상태를 판 안에서 유지한다. 화면 밖 목표는 가장자리 화살표로 안내한다. 평상시 수집 목적지는 상자 우선, 긴급 회피 후 다시 접근한다.
- 2026-10-27 사용자는 상자 보상을 기존 강화 3개 중 1개 선택으로 임시 연결하도록 확정했다. 별도 아이템 효과와 합성은 이후 범위다. 구현 착수 전 사용자가 귀가 후 재개를 위해 중지했다.

## 검증과 비범위
- 위아래 좌표·긴 이동·경계 탐색에도 외부 청크가 캐시에 생기지 않으며 벽을 통과하지 않는다.
- 여러 시드에서 가구 증가·통로 폭·재생성 재현성을 확인한다.
- 위/아래 벽 근처의 평상시 이동·긴급 회피, 숲 기존 동작을 확인한다.
- 상자 개봉은 한 번만 적용하고 미도달/도달 불가 목표는 AI를 영구 정지시키지 않는다. 새 판은 초기화한다.
- 합성·등급 효과·상자 전용 보유 아이템 UI·새 빌드·푸시·장시간 성능 검사는 별도 요청 범위다.

승인 해석: 도서관 수정과 상자 탐색/안내 자체는 이번 사용자 요청으로 승인되어 진행한다. 미정 보상만 답변에 의존한다. 기존 작업 폴더와 단일 Editor를 사용하고 무관한 복구 씬/Profiler 자료를 보존한다.
