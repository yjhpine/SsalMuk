# 도서관 경계·책장과 상자 탐험

사용자 요청: 불필요한 위아래 청크 제거, 벽 밀착 이동 완화, 책이 꽂힌 연속 책장 벽, 더 많은 가구, 랜덤 상자와 방향 화살표, 상자 우선 AI.

## 확정된 범위와 방식
- 도서관은 Y=0 청크만 생성/보관/표시한다. Y≠0은 청크를 만들지 않고 지형 질의에서 막힌 경계로 판정한다. 내부 Y=[3,29), 좌우 확장과 내부 상하좌우 이동은 유지한다.
- 단순히 외부 청크를 숨기는 방식은 충돌/탐색의 불필요한 생성이 남는다. 유한 높이를 지형 질의에도 반영하는 방식을 선택한다. 다른 맵의 청크 규칙은 유지한다.
- 벽은 청크당 한 정적 메시 안에 나무 프레임·선반·다색 책등을 반복 배치한다. 책마다 GameObject/Collider를 만들지 않는다. 내부 가구는 격자 슬롯의 확률 배치로 늘리고 중앙/가장자리 통로와 보스 통과 폭을 확보한다.
- AI는 도서관 벽에서 평상시 약 3.5단위의 몸통 여유를 선호하며 접근 중 미리 감속하고 안쪽으로 복귀한다. 가까운 경험치·버프·상자 접근과 현재 이동 중인 검증된 길찾기 경유점에는 여유를 완화해 수집과 가구 우회를 막지 않는다. 긴급 회피는 즉시 접촉·돌진 위험을 먼저 비교하고 같은 위험의 후보끼리 적 간격과 예상 벽 여유를 함께 평가한다. 돌파는 덜 막힌 통로를 먼저 고르되 벽을 미리 살펴 기존 방향을 재선정한다. 숲의 기존 이동 평가는 유지한다.
- 벽 옆 돌파가 평행 또는 바깥 방향을 유지하면 기존 계획 주기(0.2초)마다 열린 안쪽 길을 다시 비교한다. 벽 자체가 막힌 방향 비율을 높여 돌파 해제를 막는 상황에서도 복귀할 수 있게 하며, 방향이 그대로라면 기존 정체 시간을 보존한다.
- 상자는 두 맵의 접근 가능한 위치에 결정적으로 랜덤 배치하고 열린 상태를 판 안에서 유지한다. 화면 밖 목표는 가장자리 화살표로 안내한다. 사용자 후속 정정에 따라 상자로 향하는 동안 가까운 경험치를 흡수 반경까지 짧게 우회해 수집한다. 먼 경험치를 쫓아 상자 반대 방향으로 돌아가지 않으며 긴급 회피 후 원래 상자 접근을 재개한다.
- 2026-10-27 사용자는 상자 보상을 기존 강화 3개 중 1개 선택으로 임시 연결하도록 확정했으며 중지 후 재개를 지시했다. 별도 아이템 효과와 합성은 이후 범위다.
- 임시 상자는 플레이어 주변 3×3의 플레이 가능한 청크마다 한 곳을 시드/좌표로 정한다. 각 청크의 연결된 중앙 공간에서 몸통 폭으로 도달 가능한 지점만 사용한다. 도서관은 Y=0의 3개 가로 청크만 대상이며 신규 청크 진입 때 생성한다. 열린 레코드는 지형 캐시와 별개로 판 안에서 보존하고 새 판에서 초기화한다.
- 상자 중심 0.85 이내에 도달하고 사이에 장애물이 없으면 한 번 개봉한다. 레벨·경험치를 올리지 않는 별도 보상 선택권을 적립한다. 현재 레벨업 선택은 유지하고 다음 선택에서 상자 보상을 먼저 제시한다. 선택하지 않은 추가 레벨업·상자 보상은 각각 보존한다.
- 상자 보상은 수동 선택이며 기존 레벨업 AUTO를 상자에 적용하지 않는다. 전투는 계속되고 ESC 일시정지 동안 개봉·선택 적용이 멈춘다. 별도 등급·아이템 보유 UI는 만들지 않고 기존 강화 카드 3개와 상자 보상 제목을 사용한다.
- 상자와 화살표는 런타임 표시만 생성한다. 상자는 보이는 범위에서 풀링하고 도형을 메시 하나로 묶으며 개별 Update·물리 콜라이더를 만들지 않는다. 방향 표시는 현재 상자 목적지가 화면 밖일 때만 가장자리 화살표와 거리로 나타낸다.

## 검증과 비범위
- 위아래 좌표·긴 이동·경계 탐색에도 외부 청크가 캐시에 생기지 않으며 벽을 통과하지 않는다.
- 여러 시드에서 가구 증가·통로 폭·재생성 재현성을 확인한다.
- 위/아래 벽 근처의 평상시 이동·긴급 회피, 숲 기존 동작을 확인한다.
- 상자 개봉은 한 번만 적용하고 미도달/도달 불가 목표는 AI를 영구 정지시키지 않는다. 새 판은 초기화한다.
- 합성·등급 효과·상자 전용 보유 아이템 UI·새 빌드·푸시·장시간 성능 검사는 별도 요청 범위다.

승인 해석: 도서관 수정과 상자 탐색/안내 및 임시 기존 강화 보상은 사용자 요청과 후속 답변으로 승인됐다. 기존 작업 폴더와 단일 Editor를 사용하고 무관한 복구 씬/Profiler 자료를 보존한다.
