# 탐험·상자 아이템·합성 기획 초안

- 작성일: 2026-09-30
- 상태: 상자·아이템·합성 세부 규칙은 협의 단계. 맵 선택은 2026-10-27 별도 승인.
- 이번 범위: 플레이 흐름과 화면 요구 정리.
- 기준: 사용자의 최신 대화와 [기존 게임 기획](GAME_DESIGN.md).

## 1. 기획 방향

무한 맵에서 상자를 찾아 이동하고 아이템을 모으는 파밍을 중심으로 플레이를 확장한다. 이동과 전투 운영은 기존처럼 low AI가 맡는다. 플레이어가 같은 지역을 돌며 경험치를 모으는 흐름에 새로운 탐험 목적지를 더한다.

2026-10-27 맵 방향을 확정했다. **숲**은 기존 청크 기반 무한 확장에 무작위 방 배치를 빈터로 응용하고, 통과 불가능한 나무·바위와 통과 가능한 다량의 풀을 배치한다. **도서관**은 위아래 벽으로 막힌 가로형 맵이며 좌우로 확장하고 벽 안에서 자유롭게 이동한다. 맵과 단일 스프라이트 보행의 구현은 [별도 승인 명세](../superpowers/specs/2026-10-27-map-selection-animation.md)를 따른다.

상자를 탐색 목적지로 활용하는 구상은 유지하되 개봉·등급·합성·상자 AUTO는 여전히 미정이다. 이번 맵 작업에 상자 기능을 포함하지 않는다.

## 2. 사용자가 제시한 요구

| 항목 | 현재 구상 |
| --- | --- |
| 맵과 파밍 | 무한 맵에 상자를 랜덤 배치하여 돌아다니며 아이템을 파밍 |
| 상자 보상 | 랜덤 아이템 후보 3개를 제시하고 그중 1개를 선택해 획득 |
| 아이템 설명 | 상자 아이템에 마우스를 올리면 툴팁 표시 |
| 왼쪽 UI | 강화 내역 표시 |
| 오른쪽 UI | 획득한 아이템을 먼저 얻은 것부터 최근 얻은 것 순으로 정렬 |
| 아이템 배치 순서 | 한 줄은 왼쪽 → 오른쪽, 다음 줄은 위 → 아래 순서 |
| 등급 | 상자 색깔로 아이템 등급 구분 |
| 합성 | 아이템끼리 합쳐서 결과 아이템을 얻는 기능 포함 |

여기서 정리한 내용은 기획 요구이며 구현 완료를 뜻하지 않는다.

## 3. 플레이 흐름

상자 탐색 → 상자에 접근해 획득 조건 충족 → 랜덤 아이템 후보 3개 등장 → 1개 선택·획득 → 오른쪽 목록에 반영 → 아이템 수집과 합성 → 다음 파밍 장소 탐색.

상자를 여는 조건, 상자 선택에 AUTO를 사용할지, 합성을 실행하는 주체는 아직 미정이다. 기존 레벨업 AUTO의 5초 선택 규칙을 상자나 합성에 자동으로 적용하지 않는다. 상자 보상과 합성 중 전투 진행 여부도 별도로 정한다.

## 4. 화면 구성

### 왼쪽: 강화 내역

현재 얻은 강화 내용을 확인하는 영역으로 둔다. 무기별 강화와 공용 강화를 어떻게 묶을지, 단계나 증가량을 어떤 형식으로 표시할지는 다음 기획에서 정한다.

### 오른쪽: 획득 아이템

획득 순서로 배치한다. 예를 들어 한 줄에 4개를 표시하기로 했다면 첫 줄은 1·2·3·4번째 아이템, 두 번째 줄은 5·6·7·8번째 아이템이다. 이 숫자는 정렬 설명용이며 실제 열 개수는 미정이다.

동일 아이템을 각각 표시할지 수량으로 묶을지, 목록이 길어지면 스크롤이나 페이지 중 무엇을 사용할지 정해야 한다. 합성에 사용한 재료를 목록에서 제거할지 획득 이력으로 남길지, 결과 아이템을 어느 위치에 배치할지도 미정이다.

### 툴팁

마우스를 올려 아이템 설명을 확인한다. 이름·등급·효과를 기본 정보로 제안하며 합성 재료나 가능한 조합을 함께 보여줄지는 추가 결정한다. 상자 보상 화면과 오른쪽 보유 목록에서 같은 설명을 볼 수 있도록 하는 것은 제안 사항이다.

## 5. 등급과 합성에서 정할 내용

| 주제 | 미정 사항 |
| --- | --- |
| 등급 체계 | 등급 수, 이름, 대응하는 상자 색 |
| 보상 등급 | 상자 색과 같은 등급만 나오는지, 색별 확률표를 사용하는지 |
| 보상 후보 | 같은 상자의 3개에 중복 아이템을 허용하는지 |
| 아이템 효과 | 능력치·고유 효과·기존 일시적 버프와의 관계, 중복 효과 규칙 |
| 합성 재료 | 같은 아이템 여러 개를 합치는지, 서로 다른 지정 조합을 사용하는지 |
| 합성 결과 | 상위 등급·새 효과·정해진 결과 또는 랜덤 결과 중 어떤 방식인지 |
| 합성 실행 | 수동·자동 여부, 재료 수·소모 규칙, 실패 가능성·비용 |
| 획득과 보관 | 즉시 효과 적용 또는 장착 여부, 보유 제한과 정렬 방식 |
| 판 종료 | 기존 성장 초기화에 새 아이템·합성을 어떻게 포함할지 |

## 6. 맵·AI와 함께 정할 내용

- 상자 위치·등급·보상이 같은 판에서 유지되는 범위와 개봉 후 재등장 여부.
- 상자를 AI가 발견하는 범위와 발견하지 못했을 때 탐험 방향.
- 상자, 주변 경험치, 보스 대응 사이의 목표 우선순위.
- 긴급 회피 후 파밍 목표로 복귀하는 조건과 한 지역에 머무는 기준.
- 계속 이동할 때의 원거리 일반 몬스터 보존과 전역 500마리 상한의 관계.

## 7. 기획 확정 후 확인할 동작

- 상자 보상에 랜덤 아이템 후보 3개가 나타나며 확정된 등급 규칙을 따른다. 선택한 1개만 한 번 획득하고 오른쪽 목록에 반영한다.
- 왼쪽 강화 표시와 실제 강화 내역이 일치한다.
- 오른쪽 아이템 목록이 획득 순서와 왼쪽 → 오른쪽, 위 → 아래 배치를 지킨다.
- 마우스를 올린 아이템과 툴팁의 이름·등급·효과가 일치한다.
- 합성 시 확정된 재료 소모와 결과 지급이 한 번씩 적용되며 목록도 같은 상태를 표시한다.

상자 보상은 3개 중 1개 선택으로 확정했다. 이어서 맵 방식의 채택 여부와 등급·아이템 효과·합성 규칙을 구체화한다.
