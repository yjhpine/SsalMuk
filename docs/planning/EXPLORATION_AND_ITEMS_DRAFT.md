# 탐험·상자 아이템·합성 기획

- 최초 작성: 2026-09-30, 최신 승인: 2026-11-04.
- 24종·18레시피·수치·중복 효과·상자 확률은 사용자의 `진행`으로 첫 구현 기본값이 승인됐다.
- 상세 계약: [아이템·합성 승인 설계](../superpowers/specs/2026-11-04-items-and-synthesis-design.md).
- 구현·검증 상태: [재개 지점](../development/HANDOFF.md). 이 문서는 게임 기획 기준이며 전체 실행 검증을 뜻하지 않는다.

## 플레이 흐름

가까운 경험치를 주우며 상자로 이동 → 접근 시 한 번 개봉 → 같은 등급의 서로 다른 아이템 후보 3개 → 1개 수동 선택 → 획득순 목록에 추가 → 보유하거나 3개 합성 → 다음 상자 탐색.

전투는 보상·합성 중에도 계속되며 ESC에서만 정지한다. 기존 레벨업의 5초 AUTO는 유지하고 상자·합성에는 적용하지 않는다. 이미 열린 레벨업 선택을 보존하며, 다음 선택부터 누적 상자 보상을 먼저 처리한다.

## 등급과 아이템

| 색상 | 등급 | 초기 종류 수 |
| --- | --- | ---: |
| 회색 | 커먼 | 6 |
| 초록색 | 언커먼 | 6 |
| 파란색 | 레어 | 4 |
| 노란색 | 레전더리 | 4 |
| 빨간색 | 얼티밋 | 4 |

상자 생성 시 등급을 고정하고 같은 등급의 후보만 제시한다. 기본 등급 가중치는 65 / 25 / 8 / 1.8 / 0.2다. 하위 등급은 공격력·공속·이속·회복·흡수 범위·경험치, 상위 등급은 능력치와 흡혈·번개·처치 폭발·보호막을 함께 제공한다. 상세 수치는 승인 설계를 따른다.

보유 즉시 적용하고 동일 아이템을 여러 개 가질 수 있다. 능력치는 합산하며 같은 고유 효과 계열은 하나의 발동 간격을 공유한다. 아이템 피해가 다른 아이템 효과를 다시 발동시키지 않는다. 기존 바닥의 일시적 버프와 별도이며, 사망·새 판에서 보유·효과·선택권·합성 예약을 초기화한다.

## 화면

- 왼쪽: 보유 무기의 공격력·개수·공속·범위 단계와 공용 강화 4종. 긴 내역은 세로로 스크롤한다.
- 오른쪽: 소유 인스턴스별로 획득순 4열 배치. 왼쪽→오른쪽, 위→아래 순서이며 긴 목록을 스크롤한다.
- 툴팁: 이름·등급·실제 효과·중복 규칙·관련 확정 레시피를 표시한다. 이름은 해당 등급 색상이고 화면 밖으로 나가지 않는다.
- 아래쪽: 상자 3개 선택 카드 또는 합성 패널. 합성은 선택 재료·랜덤 후보·확정 결과·실행 불가 이유를 보여준다.
- 상자/레벨업 선택이 나타나면 합성창을 잠시 숨기고, 보유 중인 선택 재료는 복귀 시 유지한다.
- 상자 방향 안내는 좌우 HUD와 아래 보상/합성 패널 사이의 전투 영역에 표시한다.

## 합성

같은 등급의 서로 다른 소유 인스턴스 3개를 재료로 쓴다. 동일한 아이템 종류 여러 개는 허용하지만 동일 인스턴스 ID를 반복할 수 없다.

- 랜덤 합성: 한 단계 높은 등급의 아이템 1개.
- 확정 합성: 승인된 18개 레시피 중 재료 수량이 일치하는 결과 1개. 재료를 고른 순서는 무관하다.
- 확정 조합에서도 랜덤 합성을 선택할 수 있다. 얼티밋은 더 합성하지 않는다.
- 별도 비용·실패 확률 없이 재료 3개와 효과를 함께 제거하고 결과를 목록 끝에 추가한다.
- 중복 클릭·이미 소모한 재료·이전 판·오래된 목록 상태의 요청은 현재 소유 상태를 보존하며 거절한다.

## 유지하는 맵·AI 계약

숲은 무한 청크의 빈터·통로·막히는 나무/바위·통과 가능한 풀, 도서관은 위아래 책장 경계 안에서 자유롭게 이동하는 가로 확장 맵이다. 플레이어는 기존 한 장 스프라이트 보행을 유지한다.

상자는 같은 판에서 재등장하지 않는다. 상자를 장기 목적지로 유지하며 가까운 경험치를 줍고, 긴급 회피·돌파를 먼저 처리한다. 원거리 일반 몬스터·보스·경험치 보존과 일반 상한 500을 유지한다.

이번 범위에는 별도 생존 AI 변경, 더 넓은 탐험 방향 설계, 상자 AUTO, 재등장 규칙 변경이 포함되지 않는다. 전체 회귀·30분 플레이·새 빌드·푸시는 별도 지시를 따른다.
