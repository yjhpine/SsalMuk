## 1. 게임의 중심

플레이어가 레벨업 보상을 직접 선택하고, low AI가 이동·경험치 수집·전투 운영을 대신하는 방치형 뱀서라이크다. 공격은 자동으로 실행된다.

AI가 위험을 감수하며 경험치를 챙기고 포위 상황을 돌파하는 모습을 보면서, 플레이어는 무기 조합과 강화 방향을 결정한다. 조작의 중심은 직접 이동하거나 공격하는 것이 아니라 전투 중 계속 주어지는 성장 선택이다.

한 판은 사망할 때까지 이어지는 무한 생존이다. 보스 처치는 클리어 조건이 아니다. 사망하면 해당 판의 성장 내역을 초기화한다.

## 2. 시작과 한 판의 흐름

### 확정 기획

1. 메인 메뉴에서 철검·철창·철도끼·파이어볼 중 시작 무기를 하나 고른 뒤 `게임 시작`(`GameStart`) 버튼을 누른다. 기본 선택은 철검이다.
2. 전투 씬을 로드한다.
3. 초기 맵과 구조물을 생성한다.
4. 플레이어를 생성한다. 선택한 무기 하나만 기본 상태로 장착한다.
5. 몬스터를 생성한다.
6. 자동 전투를 시작한다.
7. 이동·전투·경험치 수집·레벨업 선택을 반복한다.
8. 플레이어가 사망하면 해당 판을 끝내고 성장 내역을 초기화한다.
9. 종료한 판의 결과를 확인하고 다시 시작하거나 메인 메뉴로 돌아간다.

전투에 필요한 맵·구조물·플레이어·몬스터는 씬에 미리 배치하지 않고 실행 중 생성한다. 초기 생성에는 위의 순서가 있다. 전투가 시작된 뒤에는 맵 확장과 몬스터 출현이 계속된다.

레벨업 선택창을 열어도 전투는 멈추지 않는다. 선택 중에도 low AI의 이동, 자동 공격, 몬스터 행동, 피격과 경험치 수집이 계속된다.

메인 메뉴에는 **게임 시작·설정·종료** 버튼을 가로로 배치한다. 전투 중 ESC를 누르면 **게임 재개·설정** 버튼을 세로로 표시하며 전투·스폰·아이템 시간·생존 시간을 멈춘다. 설정에서 돌아오면 정지 메뉴를 유지하고, 게임 재개 또는 ESC를 누르면 이어진다. 레벨업 선택지는 정지 중 숨겼다가 재개 시 그대로 표시한다. 설정의 **다크모드**는 기본 켜짐이며 전투 배경을 어둡게 하되 유닛·공격·경험치 색은 유지한다. 변경은 즉시 반영하고 다음 실행에도 저장한다.

생존 시간은 초기 생성이 끝나 자동 전투를 시작하는 시점부터 측정하는 것을 기본 기준으로 삼는다. 씬 로드와 초기 생성에 걸린 시간은 포함하지 않으며, 레벨업 선택 중에도 계속 흐른다. 생존 시간에 따른 난이도와 보스의 5분 출현 주기도 이 기준을 따른다.

### 사망 시 초기화

- 획득한 무기와 각 무기의 강화 내역
- 캐릭터 레벨과 경험치 등 해당 판의 성장 상태
- 아직 사용하지 않은 레벨업 선택 기회

다음 판에 성장 효과를 누적하는 영구 강화는 적용하지 않는다. 다시 시작하면 직전에 고른 시작 무기 하나로 새로 시작한다. 메인 메뉴에서는 다른 시작 무기를 고를 수 있다.

### 사망 결과와 다음 행동

사망 결과 화면에 종료한 판의 **생존 시간·처치 수·플레이어의 최종 레벨**을 표시한다. 성장 상태를 초기화하더라도 결과 화면에는 종료한 판의 기록을 표시한다.

- **다시 시작:** 새 전투 씬을 로드하고 초기 맵·구조물 → 플레이어 → 몬스터 생성 순서로 새 판을 시작한다.
- **메인 메뉴:** `GameStart` 버튼이 있는 메인 메뉴로 돌아간다.

## 3. 플레이어와 low AI의 역할

| 주체 | 역할 |
| --- | --- |
| 플레이어 | 게임 시작, 레벨업 선택지에서 무기·특정 무기의 강화·공용 강화 선택, 사망 후 다시 시작 또는 메인 메뉴 선택 |
| low AI | 이동 입력, 위험 회피, 바닥에 떨어진 경험치 수집, 포위 판단과 탈출 방향 결정 |
| 자동 공격 | 목표를 정하고 보유한 무기의 공격 실행 |

대화에서 나온 D키 등 이동키는 이동 입력을 설명하기 위한 예시다. 실제 플레이에서 이 입력은 low AI가 대신한다.

### 이동 운영

- 바닥에 떨어진 경험치를 적극적으로 수집한다.
- 근처 보스의 공격·접근 가중치를 높인다. 접근 가능한 주변 경험치가 충분하면 보스 접근보다 수집을 우선하며, 적은 경험치만 있으면 보스에 집중한다. 근처 드롭 아이템도 수집하고 긴급 회피·포위 탈출을 우선한다.
- 수집할 경험치가 없으면 가까운 적에게 보유 근접 무기의 현재 공격 사거리 안으로 접근해 공격 기회를 만든다. 접근 도중 사거리에서 감속할 것을 포함해 위험을 판단한다.
- 위험을 완전히 피하는 운영보다, 적과의 간격을 조절하면서 위험한 위치의 경험치도 노리는 공격적인 운영을 지향한다.
- 직접적인 충돌 위험이 커지면 적을 피한다.
- 주변의 일정 범위에서 적이 대부분의 이동 경로를 막으면 포위 상황으로 판단한다.
- 포위되면 AI가 탈출 방향 하나를 정하고, 그 방향으로 길을 뚫어 빠져나간다.

AI는 피격과 사망이 가능한 전투 규칙 안에서 경험치 수집과 탈출을 선택한다.

### 공격 목표

| 상황 | 공격 목표 |
| --- | --- |
| 평상시 | 거리와 보스 가중치로 선택. 가까운 일반 적보다 근처 보스에 집중할 수 있음 |
| 포위 돌파 중 | 선택한 탈출 방향을 막는 적 우선 |
| 포위에서 탈출한 뒤 | 거리와 보스 가중치를 사용하는 기본 규칙으로 복귀 |

목표 선택 규칙은 모든 무기에 공통으로 적용한다. 실제로 피해를 주는 모양은 각 무기의 공격 형태를 따른다.

구체적인 FSM 상태·위험 평가·탈출 방향·종료 조건은 승인된 구조 설계와 구현 계획 B1을 따른다. 이 문단은 행동의 목적을 정하며 정확한 임계값과 거리는 임시 프리셋으로 구현한 뒤 조정한다.

### 플레이어 피격 반응과 보호

플레이어가 실제로 피해를 받으면 몬스터와 비슷한 피격 느낌을 준다. 스프라이트가 빨간색으로 1회 점멸하고, 커졌다가 원래 크기로 돌아오며, 뒤로 넉백된다.

- 플레이어가 피해를 받으면 짧은 무적 시간을 적용한다.
- 이 시간 동안 추가 피해를 막아 한순간에 여러 번 피해를 받지 않게 한다.
- 무적 시간이 끝나면 다시 피해를 받을 수 있다.
- 무적 시간은 짧게 유지하며, 정확한 지속 시간은 밸런스 조정에서 정한다.

## 4. 플레이어의 시각적 움직임

플레이어는 스프라이트 한 장으로 이동하는 느낌을 낸다. 스프라이트 바닥을 기울임의 기준점으로 두고, 기울기와 상하 움직임을 반복한다.

**왼쪽으로 기울며 상승 → 정자세로 돌아오며 하강 → 오른쪽으로 기울며 상승 → 정자세로 돌아오며 하강**

- 걷는 연출의 기준은 low AI의 이동 입력이다.
- 이동 입력이 있을 때 걷는 연출을 재생한다.
- 정지 상태에서는 본체가 정자세를 유지한다.
- 공격 자체가 걷는 연출을 시작시키지는 않는다.
- 본체에 별도의 공격 모션을 넣지 않고, 무기가 나타나 공격하는 느낌으로 표현한다.
- 이동하지 않는 동안에도 목표를 자동 공격한다.

플레이어와 몬스터의 2D 스프라이트는 AI로 제작할 수 있다. 같은 화풍·시점·픽셀 밀도를 맞춘 투명 배경의 단일 스프라이트를 사용한다. 2026-09-17 사용자 지시에 따라 좌우 기울임·상하 점프 보행은 플레이어에만 적용한다. 일반·공중·보스는 정자세로 이동하며 피격 점멸·팽창·넉백은 유지한다. 같은 날 추가 지시로 플레이어와 모든 몬스터의 바닥 그림자를 제거한다. 공격 이펙트와 경험치 발광은 유지한다. 공격 이펙트는 공개된 2D 에셋을 조사해 활용한다. 제작 방향과 조사 후보는 [아트·이펙트 기준](ART_AND_VFX.md)에 정리한다.

아래 이미지는 사용자가 제공한 기울기 참고 그림이다. 확정된 스프라이트 원화가 아니다.

## 5. 무기 4종

여러 종류의 무기를 동시에 장착할 수 있다. 시작 무기는 메인 메뉴에서 고른 하나이며, 나머지 무기는 레벨업 선택을 통해 획득한다.

추가 사용자 지시: 무기 외형은 도트 스타일의 **철검·철도끼·철창·끝에 루비가 달린 금색 마법 지팡이**로 제작한다. 지팡이는 파이어볼의 발사 무기 표시이며 기존 무기 4종·강화 5종 규칙을 유지한다.

| 무기 | 기본 공격 형태 | 공격 범위 강화 시 변화 |
| --- | --- | --- |
| 검 | 전방 60도 범위로 휘두름 | 60도 각도를 유지하면서 베는 거리 증가 |
| 창 | 전방으로 내지름 | 찌르는 거리 증가 |
| 대형 도끼 | 플레이어 주변을 한 바퀴 회전하는 공격 | 회전 공격 반경 증가 |
| 파이어볼 | 원거리로 발사되며 첫 적에게 명중하면 폭발하고 소멸하는 마법 공격, 소모 코스트 없음 | 폭발 반경 증가 |

검·창·파이어볼은 선택한 목표를 향해 공격한다. 대형 도끼는 목표 선택 규칙을 공유하되 공격 형태는 한 바퀴 회전으로 유지한다.

파이어볼은 첫 적에게 명중한 위치에서 폭발하고 투사체가 사라진다. 적을 관통하지 않으며, 폭발 범위 안의 적들에게 피해를 준다. 빗나간 투사체는 화면 밖 여유 거리 2+투사체 반경을 지나면 폭발 없이 소멸하며 최대 수명 3초도 유지한다. 경계 이후의 먼 적에게는 해당 투사체가 명중하지 않는다. 2026-09-24 지시로 파이어볼 동시 복사본은 기본 포함 6개, 연속 공격 강화는 2레벨까지다.

공격 범위는 사용자가 제공한 이미지 느낌의 반투명 효과로 표현한다. 아래 이미지는 공격 범위의 느낌을 설명하는 참고 자료이며, 그대로 사용할 게임 에셋으로 확정한 것은 아니다.

![공격 범위 표현 참고](references/attack-range-reference.png)

타격 중복 기준과 공격 예약 방식은 승인된 구조 설계를 따른다. 무기별 타격 간격의 정확한 수치는 임시 프리셋으로 구현한 뒤 조정한다.

근접 무기의 손잡이는 공격 원점에, 공격 효과의 시각적 중심은 무기의 끝부분에 붙인다. 범위 강화와 범위 아이템으로 길어져도 실제 판정과 같은 끝점을 사용한다.

## 6. 무기별 업그레이드 5종

업그레이드는 보유 무기 전체에 공통 적용하지 않고, 선택지에 표시된 특정 무기에 적용한다.

| 업그레이드 | 효과 |
| --- | --- |
| 공격력 증가 | 해당 무기의 공격력 증가 |
| 무기 개수 증가 | 한 단계에 하나만 좌우 교대로 추가. 근접은 가운데→왼쪽 40도→오른쪽 40도→왼쪽 80도 순, 최대 총 8개. 파이어볼은 30도 간격, 최대 총 6개 |
| 연속 공격 횟수 증가 | 최대 2레벨. 강화마다 한 묶음의 공격 1회 추가, 기본 포함 최대 3연타. 2레벨 이후 해당 무기의 연속 공격 강화는 선택지에서 제외 |
| 공격 속도 증가 | 해당 무기의 공격 주기가 빨라짐 |
| 공격 범위 증가 | 해당 무기의 베기 거리, 찌르기 거리, 회전 반경 또는 폭발 반경 증가 |

무기 종류를 새로 얻는 것과, 이미 가진 무기의 개수를 늘리는 것은 별개의 선택이다.

사용자 지시에 따라 개수 강화는 근접 7레벨·파이어볼 5레벨, 연속 공격 강화는 2레벨까지다. 공격력·공격 속도·공격 범위는 최대 강화 단계 없이 누적한다. 모든 무기를 얻어도 성장은 계속된다.

### 공용 업그레이드 4종

| 업그레이드 | 단계당 효과 |
| --- | --- |
| 이동속도 | 기본 이동속도의 10% 추가 |
| 초당 회복 | 초당 체력 0.1 추가, 최대 체력을 넘지 않음 |
| 줍는 사정거리 | 기본 경험치·아이템 흡수 반경의 20% 추가 |
| 경험치 획득량 | 기본 경험치의 15% 추가, 소수값도 반올림·버림 없이 누적 |

증가율은 기본값에 선형 누적한다. 경험치 강화 1레벨에서 값 1인 구슬은 1.15, 값 2는 2.3을 준다. 소수 잔여는 다음 구슬과 레벨업 뒤에도 유지하며 HUD에도 표시한다. 공용 강화는 특정 무기와 무관하게 적용하고 사망 시 초기화한다. 레벨업마다 무기별 강화와 함께 등장하며 강화 단계의 기획상 상한은 없다.

## 7. 레벨업과 선택지

### 후보 구성

레벨업 때 다음 두 범주에서 확률에 따라 선택지가 등장한다.

1. 보유한 무기의 5종 강화 중 가능한 후보와 공용 강화 4종(개수·연속 공격 상한 후보 제외)
2. 아직 보유하지 않은 무기

| 보유 상태 | 등장할 수 있는 선택 |
| --- | --- |
| 검만 보유 | 검의 강화, 공용 강화, 창·대형 도끼·파이어볼 획득 |
| 검과 추가 무기 보유 | 보유 무기 각각의 강화, 공용 강화, 아직 없는 무기 획득 |
| 4종 모두 보유 | 무기별 강화와 공용 강화만 등장 |

이미 획득한 무기는 새 무기 획득 후보에서 제외한다. 새 무기를 얻으면 그 무기의 업그레이드가 이후 선택 후보에 추가된다. 무기가 등장하는 경우와 업그레이드만 등장하는 경우 모두 가능하다.

무기와 업그레이드의 구체적인 등장 확률은 아직 정하지 않았다. 위 표가 모든 후보의 동일 확률을 의미하지는 않는다.

### 선택 기회의 누적

- 레벨업 선택 중에도 전투를 계속한다.
- 보상을 선택하기 전에 다시 레벨업하면 선택 기회를 누적한다.
- 하나를 고르면 다음 선택 기회를 제시한다.
- 이후 선택은 갱신된 무기 보유 상태를 반영해야 한다.
- 사망하면 남은 선택 기회도 해당 판과 함께 종료한다.

### 선택지 표시

한 번에 중복 없이 서로 다른 선택지 3개를 제시한다. 같은 무기의 획득 선택이나 같은 무기의 같은 업그레이드는 한 화면에 중복해서 나오지 않는다. 검 공격력 증가와 창 공격력 증가처럼 대상 무기가 다르면 서로 다른 선택지다.

중복 제한은 한 번에 제시하는 3개 사이에만 적용한다. 다음 선택 기회에는 같은 업그레이드가 다시 등장할 수 있다.

## 8. 몬스터와 난이도

| 종류 | 기획 |
| --- | --- |
| 일반 몬스터 | 공유한 플레이어 위치로 직진하고 몸이 닿으면 피해. FSM으로 생존·넉백 관리 |
| 공중 몬스터 | 뱀파이어 서바이버즈의 박쥐 같은 역할. 화면 끝에서 플레이어를 향한 직선 경로로 지나가며 접촉 피해를 유발 |
| 거대 몬스터 | 높은 기본 능력치와 접촉 피해, 빨간 예고 뒤 돌진 패턴을 가진 보스 |

- 생존 시간이 길어질수록 몬스터의 수와 능력치가 증가한다.
- 일반 몬스터는 맵 전체의 동시 존재 수에 상한을 둔다. 초기 생성과 지속 소환을 합산하고 화면 밖 개체도 포함한다. 상한에 도달하면 추가 일반 소환을 건너뛰며 대기량으로 적립하지 않는다. 기존 개체는 유지하고 빈자리가 생기면 다음 소환 일정부터 재개한다. `normalPopulationCap`의 현재 임시값은 500이며 최종 수치는 나중에 조정한다. 공중·보스·경험치에는 이 상한을 적용하지 않는다(2026-09-17 사용자 추가 지시로 300에서 500으로 변경).
- 평상시 일반 소환률은 2026-09-24 후속 지시로 기존의 1.5배인 `1.5+생존 초/80`마리/초다. 시작 직후 초당 1.5마리, 2분 초당 3마리, 5분 초당 5.25마리이며 일정은 연속 누적해 정수 마리로 생성한다. 초기 12마리와 2분 전방위 웨이브 수는 유지한다.
- 공중 몬스터는 20초마다 화면 한쪽 밖에서 무리로 등장한다. 2026-09-25 후속 지시로 한 무리는 최소 12마리에서 생존 50초마다 1마리씩 증가한다. `min(24, 12+floor(생존 초/50))`으로 5분에 18마리, 10분에 최대 24마리에 도달하며 이후 유지한다. 같은 날 방향 정정에 따라 긴 축은 진행 방향과 직각이며 플레이어 `ㅇ ← ㅣ`처럼 넓은 면이 접근한다. 3겹 중 가운데 겹이 길고 앞뒤 겹은 짧게 가운데에 맞춘다. 기본 12마리는 가운데 6·앞뒤 각 3마리, 최대 24마리는 가운데 10·앞뒤 각 7마리다. 겹 간 깊이 간격 0.65, 횡방향 개체 간격 1.3이며 출현 때 플레이어를 향해 정한 평행 직선을 유지한다. 상한은 무리별 수이며 맵 전체 공중 수 제한은 아니다.
- 보스는 **5분마다** 등장한다.
- 별도로 **2분마다 전방위 일반 몬스터 웨이브**가 현재 카메라 밖에서 쏟아진다. 첫 웨이브는 80마리이며 일반 상한 500을 함께 적용한다. 생성 여유가 없는 몫을 다음에 몰아 생성하지 않는다.
- 직전 웨이브를 빨리 정리하고 남은 적도 적을 때만 다음 웨이브를 한 단계 강화한다. 초기 기준은 직전 생성 수의 80% 이상을 45초 안에 처치하고 다음 발생 시 남은 일반 몬스터 수가 직전 생성 수의 25% 이하인 것이다. 단계마다 요청 수 20마리·기본 체력 10%·기본 피해 10%를 더한다. 버거운 상황에서는 단계를 유지하며 기존 시간 난이도는 계속 적용한다.
- 일반 몬스터는 기본 체력 10·공격력 5에서 매분 체력 +1.5·공격력 +0.8을 누적한다. 5분에는 추가 +5/+2, 10분에는 추가 +10/+4, 15분에는 추가 +15/+6처럼 보정도 누적한다. 일반 공격력은 웨이브 강화까지 포함해 최대 15다. 5분 22.5/11, 10분 40/15, 20분 90/15, 30분 160/15이며 별도 웨이브 체력 보정 전 수치다. 새로 생성되는 적에만 적용하고 기존 적의 능력치는 유지한다.
- 일반 속도는 플레이어 기본 속도의 0.95배(현재 2.85), 공중 1.1배(3.3), 보스 추적 1.2배(3.6)다. 보스 돌진은 예고 당시 강화·아이템 포함 플레이어 현재 속도의 5.2배이며 추적·돌진 속도 모두 소수 첫째 자리까지 반올림한다(강화가 없을 때 돌진 15.6). 보스 공격력은 시간에 관계없이 60 고정이다. 보스·공중 체력의 시간 배율은 `1+생존 초/600`으로 완화해 첫 보스 체력은 900이며, 공중 피해 배율은 기존 `1+생존 초/300`을 유지한다.
- 보스는 0.5초 동안 정지하며 빨간 돌진 범위를 표시한 뒤 돌진한다. 예고 시작의 방향·끝점을 고정하며 플레이어를 지나 같은 거리만큼 더 이동한다(총 길이 2배). 30% 확률로 한 번만 추가 돌진하고 새 위치에서 다시 0.5초 예고한다. 묶음 종료 뒤 5초 추적 후 다음 예고를 시작한다. 예고 시작부터 돌진 종료까지 슈퍼아머로 넉백을 무시하되 피해·피격 표현은 적용한다. 지형 차단·사망은 돌진을 취소하며 추적 중에는 기존 넉백을 적용한다.
- 이전 보스가 살아 있어도 새 보스를 추가로 생성한다. 여러 보스가 동시에 존재할 수 있다.
- 보스 돌진에 최소 거리를 추가하지 않는다. 피격 취소 뒤 넉백 중에도 다음 돌진 대기가 흐르며, 반복 피격마다 대기를 다시 시작하지 않는다. 넉백이 끝나고 대기가 끝나면 다시 예고한다.
- 보스를 처치해도 게임을 끝내지 않고 무한 생존을 이어간다.

2026-09-24 후속 지시로 일반끼리는 조금 겹치되 한곳에 쌓이지 않도록 부드럽게 벌린다. 목표 간격은 몸통 반경 합의 90%이며 밀집·지형 차단 때 더 겹칠 수 있다. 보스는 일반에게 막히거나 감속하지 않고 추적·돌진 중 주변 일반을 강하게 밀어낸다. 두 종류 모두 지형은 통과하지 않는다. 모든 지상 적은 같은 이동 주기 시작의 플레이어 위치를 공유하고 직진하며, 개별 길찾기나 회피 판단은 추가하지 않는다. 공중은 지상 밀집·구조물을 무시하고 원래 직선으로 통과한다. 플레이어 강제 분리, 군중 밀림에 의한 피해는 없고 기존 접촉 피해와 피격 넉백은 유지한다.

몸통과 피격 영역을 분리한다. 원형 판정의 기준 지름은 표시 스프라이트의 짧은 변이다. 2026-09-18 후속 지시에 따라 몬스터 몸통 지름은 100%, 플레이어 몸통 지름은 80%, 몬스터 피격 지름은 110%다. 몸통은 지형 충돌·길찾기·플레이어 접촉 피해에 사용하고, 더 큰 피격 영역은 검·창·도끼·파이어볼 명중과 폭발 적중에 사용한다. 시각적 팽창이나 보행이 판정 크기를 바꾸지 않는다. 기존 발 위치도 별도로 보존한다.

### 공통 피격 표현

몬스터가 피해를 받으면 다음 반응을 보인다.

- 스프라이트가 빨간색으로 1회 점멸한다.
- 스프라이트가 커졌다가 원래 크기로 돌아온다.
- 뒤로 넉백된다.

공중 몬스터는 피격으로 넉백된 뒤 원래 진행 방향으로 다시 직진한다.

크기 변화량, 점멸 시간, 넉백 거리와 지속 시간은 나중에 조정한다. 보스를 포함한 대상별 넉백 강도는 밸런스 조정에서 정한다.

## 9. 무한 맵과 경험치

카메라는 이전보다 가까이 보여 주며 현재 orthographicSize는 10에서 8로 조정한다. 웨이브와 기존 스폰·화면 밖 소멸은 확대된 실제 카메라 경계를 기준으로 계산한다.

- 뱀파이어 서바이버즈처럼 플레이가 이어지는 방향으로 맵이 계속 생성된다.
- 시작 시 초기 맵과 구조물을 먼저 생성한다.
- 맵은 경계 벽이 없는 개방형 바닥이다. 버려진 책장·책상·의자를 드문드문 놓고, 가구 사이와 청크 경계에 넓은 통행 공간을 남긴다.
- 가구는 낡고 기울어진 외형으로 표시한다. '40% 정도 기울어진 느낌'은 외형 방향이며 장애물 면적 40%나 정확한 회전 각도 규칙이 아니다. 외형과 단순한 바닥 충돌 영역을 분리한다.
- 구조물은 플레이어와 지상 몬스터가 통과할 수 없고 공격으로 파괴되지 않는 장애물이다.
- 플레이어는 길찾기로 구조물을 우회한다. 지상 몬스터는 공유한 위치로 직진하며 지형 충돌 시 정지·슬라이드한다.
- 바닥에 떨어진 경험치를 수집해 레벨업한다.
- 멀리 벗어난 구역의 경험치와 일반·보스 몬스터를 계속 유지한다. 공중 무리는 직선 돌진 후 진행 방향으로 화면 밖 여유 거리를 통과하면 퇴장한다. 퇴장은 처치·경험치를 주지 않는다.

플레이어는 구조물을 우회하고 지상 몬스터는 막히면 정지·슬라이드한다. 공중 몬스터는 구조물을 무시하고 직선으로 통과한다.

화면 밖 보존은 구조 설계 대화에서 확정했으며, 2026-09-17 사용자 설명에 따라 공중 무리의 돌진 후 퇴장을 예외로 정정했다. 화면 밖에서 진입 중인 공중 개체는 유지하고 넉백이 끝나 원래 비행으로 돌아온 뒤 퇴장을 판단한다. 현재 퇴장 여유 거리는 화면 경계 밖 4월드 단위이며 몸 반경까지 벗어나야 한다. 사망한 몬스터, 수집한 경험치, 종료한 판은 정상 규칙에 따라 정리한다.

### 경험치 구슬과 흡수

- 경험치는 바닥에 떨어지는 **작고 동그란 원형 구슬**이다.
- 경험치 양은 **초록 < 파랑 < 빨강** 순으로 많다. 각 색의 구슬은 밝은 중심과 주변의 빛 번짐으로 발광하는 느낌을 준다.
- 플레이어가 가까이 가면 구슬이 플레이어를 향해 날아오기 시작한다.
- 가까워진 순간에는 경험치를 더하지 않는다. **구슬이 플레이어에게 닿는 순간에만 해당 값을 한 번 더한다.**
- 흡수를 시작한 구슬은 움직이는 플레이어를 따라가며, 구조물과 몬스터에 막히지 않게 처리한다. low AI는 이미 날아오는 구슬을 다시 쫓지 않는다.
- 바닥에서 대기 중인 구슬은 기존 위치를 유지한다. 흡수 중인 구슬은 현재 위치와 상태를 유지하며, 화면 밖이라는 이유로 삭제하거나 미리 획득 처리하지 않는다.
- 플레이어가 사망하면 추가 경험치를 얻지 않는다. 이전 판의 흡수나 표시 효과가 새 판에 경험치를 전달하지 않는다.

색별 경험치 값·구분 기준, 흡수 시작 거리·이동 속도·빛 번짐의 강도는 조정 가능한 수치다. 2026-09-18 사용자 지시에 따라 흡수 반경은 1.5에서 30% 늘린 1.95를 사용한다. 근접 시 비행을 시작하고 플레이어에 닿을 때 경험치를 지급한다.

### 드롭 아이템 4종

몬스터 처치 시 낮은 확률로 아이템 하나를 떨어뜨린다. 임시 확률은 2%이며 네 종류를 같은 비율로 고른다. AI가 가까운 아이템에 접근하고 흡수 반경 안에 들어오면 획득한다. 미수집 아이템은 화면에서 멀어져도 유지하며 판 종료 시 정리한다.

여기서 하네스는 게임 속 low AI의 실행기를 뜻하지 않는다. 사용자와의 대화로 개발 규칙을 정하고, Codex가 그 규칙에 따라 개발·수정·검증하는 작업 환경이다.

- 실제 작업 프로젝트는 `C:\Users\ace21\Desktop\SsalMuk`이다.
- 게임 기획을 먼저 정리하고, 그 결과로 구조를 설계한 뒤 Unity 작업을 진행한다.
- 해당 프로젝트에서 작업하고, 작업 단위를 확인한 뒤 커밋하는 흐름으로 진행한다.

### 개발·검증 규칙

1. 구현 전에 이번 작업이 어느 기획 항목을 충족하는지 확인한다.
2. 미확정 제안을 확정 규칙처럼 구현하지 않는다. 동작을 바꾸는 선택은 대화에서 정리한다.
3. 기존 사용자 변경을 보존하고, 이번 작업에 속한 변경만 커밋한다.
4. 씬이 열리거나 화면이 보인다는 사실과 실제 플레이 규칙이 동작한다는 사실을 구분한다.
5. 변경한 동작에 맞는 검증을 수행하고, 확인하지 못한 항목은 성공했다고 보고하지 않는다.
6. 저장소 밖으로의 공개·푸시는 로컬 작업과 커밋 지시에 포함된 것으로 간주하지 않는다.

구체적인 도구 구성, 검증 결과 계약, 기록 위치와 코드·씬 수정 방식은 [개발 하네스 설계](../development/HARNESS.md)에 정리했다. A1~A5의 기반·맵·이동·런타임 생성 검증을 수행했으며, AI·피해·성장 검증은 해당 기능 구현 단계에서 이어간다.
